# 🌍 Заселись — Платформа для путешествий

> Современный сервис для поиска и бронирования туров и отелей

---

## 📋 О проекте

**Заселись** — веб-приложение для туристического агентства, позволяющее пользователям находить туры и отели, оформлять страховку и связываться с менеджерами. Проект включает клиентскую часть на Vue.js и административную панель.
прод - https://zaselistravel.ru/
---

## 🚀 Стек технологий

### Frontend
- **Vue 3** — реактивный UI
- **Vue Router** — навигация между страницами
- **Axios** — HTTP запросы к API

### Backend
- **Laravel** — REST API
- **Laravel Sanctum / Token Auth** — аутентификация через Bearer токен

### Прочее
- **jQuery** — мобильная навигация
- **Bootstrap** — сетка и компоненты

## ⚙️ Установка и запуск

### Требования
- Node.js >= 18
- PHP >= 8.2
- Composer
- MySQL

### Запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

### Backend

```bash
# Установка зависимостей
composer install

# Копируем .env
cp .env.example .env

# Генерируем ключ
php artisan key:generate

# Миграции
php artisan migrate

# Запуск сервера
php artisan serve
```
Либо используем докер :)

## 🔐 Аутентификация

Авторизация реализована через Bearer токен:

1. Токен сохраняется в `localStorage` при входе
2. При каждом запросе токен подставляется в заголовок `Authorization`
3. При выходе токен удаляется и пользователь перенаправляется на `/login`

### Роли пользователей

| Роль | Доступ |
|------|--------|
| `user` | Личный кабинет, бронирования |
| `partner` | Панель партнёра |
| `admin` | Административная панель |
